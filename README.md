# GameBoost Pro

GameBoost Pro is a modern game optimization dashboard designed for online gaming performance.

## Features
- FPS and latency monitoring
- Game library for popular online titles
- One-click optimization presets
- Network cleanup and traffic prioritization
- Safe-mode and boost controls

## Run locally
Open `index.html` in a browser.

You can also serve it locally with a simple static server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Project structure
- `index.html` — dashboard layout
- `styles.css` — visual styling and responsive design
- `app.js` — interactivity and boost animation
